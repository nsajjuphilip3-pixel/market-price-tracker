# Market Price Tracker

Farmers often sell to the first middleman who offers a price because they do not know what produce fetches in the next town.

- Full tutorial: [TUTORIAL.md](TUTORIAL.md)
- Run: `python app.py` then open http://127.0.0.1:8000
- Test: `python -m unittest discover -s tests`
- Requires: Python 3.8+ only
